# d3tools Documentation

d3tools provides shared workflow configuration, datasets, and execution for
the DOOR, DAM, and DRYES engines.

- **Workflow operators:** start with the [User Guide](user-guide/index.md).
- **People extending d3tools or integrating it from Python:** use the
  [Developer Guide](developer/index.md).

For extension seams and contributor checks, see
[Developer Guide — Extensions and contributions](developer/extensions.md).
